Add Copilot instruction definitions here as YAML files. Nested folders are
mirrored beneath `.github/instructions/rules/` when generated.

The `agentic_rules/` subdirectory contains project-agent guidance rules.
`agentic_rules/sandbox.yaml` is scoped to
`agentic_rules/settings/sandbox.yaml` and guides agents to update the YAML
source and regenerate VS Code settings instead of editing generated JSON.
